| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, avatar overlap margin, dot spacing |
| sm | 8px | Log entry margin-bottom, tab gap, compact padding |

## Interaction Contracts

### Split-Pane Workspace Layout

- Left panel: 400px fixed width, non-resizable
- Right panel: flex: 1, fills remaining space
- Full viewport height minus main padding: `height: calc(100vh - 48px)`
- Chat panel scrolls independently; tab content scrolls independently
- Chat input pinned to bottom of left panel

### Tab Behavior

- 4 tabs: Deliverable, Agent Log, Build Log, Files (N)
- Default active tab: Build Log while task is `working`; Deliverable when task is `completed` and primaryFile exists
- Files tab shows count in parentheses: "Files (7)"
- Tab state is local (useState), not URL-persisted

### Build Log Live Streaming

- SSE events filtered by `data.taskId === currentTaskId`
- New entries prepend to top (newest first) OR append to bottom (oldest first, auto-scroll) -- use append with auto-scroll to match terminal behavior
- Expandable entries: click header to toggle `.open` class
- Approval cards render inline when `task:transition` event fires with `to: 'input-required'` and matching `inputType`

### Approval Card Interactions

- **Hire approval**: Amber card with role description. "Approve Hire" (btn-approve btn-sm) and "Reject" (btn-cancel btn-sm). Calls `POST /api/hire_requests/[id]/approve` or `POST /api/hire_requests/[id]/reject`.
- **Budget increase**: Amber card with current budget display. Number input pre-filled with current max. "Approve Increase" (btn-approve btn-sm). Calls `POST /api/tasks/[id]/budget` with new amount.
- Both cards disable buttons after click (prevent double-submit). Show "Processing..." while API resolves.

### File Preview

- Click file card to open inline preview below the grid
- Only one preview open at a time
- Close button (X) in top-right corner of preview panel
- Image/video/PDF served via `GET /api/deliverables/[id]/file?path=...`
- Markdown/code rendered client-side from API text response

### Settings Page

- Single column layout within `.main` content area
- "System Info" section: card with key-value pairs (Node.js version, pnpm version, DB path, worker status with green/red dot)
- "Danger Zone" section: red-bordered card at bottom with reset button
- Sidebar nav: Settings icon is U+2699 (gear symbol)
