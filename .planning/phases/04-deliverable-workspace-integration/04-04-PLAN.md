**File 1: `data/test-fixtures/eeg-sample.csv`** (D-05)

Generate a synthetic multi-channel EEG recording per Research recommendation:
- 4 channels: Fp1, Fp2, C3, C4 (standard 10-20 placement)
- 256 Hz sample rate
- 10 seconds duration = 2560 rows
- Binary labels: 0 = rest, 1 = motor_imagery
- First 5 seconds (rows 0-1279) labeled 0 (rest), last 5 seconds (rows 1280-2559) labeled 1 (motor_imagery)
- CSV format chosen over EDF because standard Python (pandas, numpy, scikit-learn) can process it directly without specialized EEG libraries

Header row: `timestamp,Fp1,Fp2,C3,C4,label`

Data generation: Use a simple mathematical model. Rest epochs have lower amplitude (base noise ~5-15uV). Motor imagery epochs have higher amplitude (base noise ~15-30uV) with a distinct pattern in C3/C4 (mu rhythm suppression simulation). Use sine waves at different frequencies + Gaussian noise.

Use a simple generation approach:
- For each row, timestamp = row_index / 256 (seconds, 3 decimal places)
- Rest (label 0): channels = random uniform in range [-15, 15] with 10Hz sine component
- Motor imagery (label 1): C3/C4 have higher amplitude [-30, 30] with 20Hz beta component, Fp1/Fp2 similar to rest
- This creates a dataset where an SVM can achieve ~70-85% accuracy on C3/C4 features, producing a meaningful confusion matrix

The executor should write a small Node.js script to generate the CSV (or generate it inline). The file should be ~100-150KB.
