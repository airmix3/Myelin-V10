`createReviewTools(ctx: ToolContext)` returns array of 3 tools:

1. **submit_for_review** (TOOL-07): No input params. Tool description: "Submit your work for supervisor review."
   - Query task: `sqlite.prepare('SELECT supervisorAgentId, state FROM tasks WHERE id = ?').get(ctx.taskId)`
   - Verify task is in 'working' state
   - Verify supervisorAgentId exists
   - Update `currentActorId` to supervisorAgentId: `sqlite.prepare('UPDATE tasks SET currentActorId = ?, updatedAt = datetime(\'now\') WHERE id = ?').run(supervisorAgentId, ctx.taskId)`
   - Emit event: `eventBus.emit('task:review', { taskId: ctx.taskId, action: 'submitted', reviewerAgentId: supervisorAgentId })`
   - Return "Work submitted for review by {supervisorAgentId}."

2. **approve_deliverable** (TOOL-08): No input params. Description: "Approve the deliverable and mark the task as completed."
   - Query task state -- must be 'working'
   - Set completedAt: `sqlite.prepare('UPDATE tasks SET completedAt = datetime(\'now\') WHERE id = ?').run(ctx.taskId)`
   - Transition to completed: `transitionTask(ctx.taskId, 'working', 'completed')`
   - Notify Tamir inbox: append to `data/agents/tamir/inbox.jsonl` with `proper-lockfile`. Entry format: `{ type: 'task_completed', taskId: ctx.taskId, department: ctx.department, agentId: ctx.agentId, timestamp: new Date().toISOString() }\n`
   - Use `fs.mkdirSync(path.dirname(inboxPath), { recursive: true })` before writing
   - Lock with `proper-lockfile.lock(inboxPath, { retries: 3, realpath: false })` -- use `realpath: false` since the file might not exist yet. Create file first if it doesn't exist.
   - Return "Deliverable approved. Task marked as completed."

3. **request_changes** (TOOL-09): Input `{ feedback: z.string().describe('Specific feedback on what needs to change') }`.
   - Query task for executorAgentId and current reviewRound
   - Store feedback: `sqlite.prepare('UPDATE tasks SET reviewFeedback = ?, reviewRound = reviewRound + 1, currentActorId = ?, updatedAt = datetime(\'now\') WHERE id = ?').run(args.feedback, executorAgentId, ctx.taskId)`
   - Emit event: `eventBus.emit('task:review', { taskId: ctx.taskId, action: 'changes_requested', feedback: args.feedback })`
   - Return "Changes requested (round {reviewRound+1}). Feedback sent to executor."

**src/lib/mcp/tools/vault.ts** -- Per TOOL-10:

`createVaultTools(ctx: ToolContext)` returns array with 1 tool:

1. **file_to_vault**: Input `{ source_path: z.string().describe('Path to the file to vault (relative to desk or absolute)'), title: z.string().describe('Title for the vault document') }`.

   **Two calling modes** (handles Tamir and other agents outside task execution context where ctx.deskDir may be empty):

   - **Mode 1: Within-task (ctx.deskDir is non-empty):**
     - Resolve source path: try relative to deskDir first (`path.resolve(ctx.deskDir, args.source_path)`), then try as absolute
     - Path traversal check: resolved path must startWith `ctx.deskDir` or `ctx.delivDir`
     - If neither, reject with "Path must be within your desk or deliverables directory"

   - **Mode 2: Direct call (ctx.deskDir is empty string):**
     - Accept absolute paths only: `path.isAbsolute(args.source_path)` must be true
     - Validate file existence: `fs.existsSync(resolvedPath)` -- reject if not found
     - Skip deskDir containment check (there is no desk to contain within)
     - Log a warning: "file_to_vault called without task context, accepting absolute path"

   **Implementation pattern:**
   ```typescript
   let srcFull: string;
   if (ctx.deskDir) {
     // Mode 1: within-task -- resolve relative to desk, validate containment
     srcFull = path.resolve(ctx.deskDir, args.source_path);
     if (!srcFull.startsWith(ctx.deskDir) && !srcFull.startsWith(ctx.delivDir)) {
       return { content: [{ type: 'text' as const, text: 'Error: Path must be within your desk or deliverables directory' }] };
     }
   } else {
     // Mode 2: direct call (e.g., Tamir outside task context)
     if (!path.isAbsolute(args.source_path)) {
       return { content: [{ type: 'text' as const, text: 'Error: When called outside a task, source_path must be an absolute path' }] };
     }
     srcFull = args.source_path;
   }
   if (!fs.existsSync(srcFull)) {
     return { content: [{ type: 'text' as const, text: `Error: File not found: ${srcFull}` }] };
   }
   ```

   Then proceed with the common path:
   - Copy to `data/vault/`: `fs.copyFileSync(srcFull, path.join(vaultDir, path.basename(args.source_path)))`
   - Read content for indexing: `fs.readFileSync(srcFull, 'utf-8')`
   - Upsert to documents table: `prisma.document.create({ data: { id: generateId('doc'), title: args.title, content: fileContent, source: 'vault', department: ctx.department, filedBy: ctx.agentId, filePath: path.join(vaultDir, path.basename(args.source_path)) } })`
   - FTS5 indexing is automatic via the INSERT trigger (from Phase 1 fts.ts)
   - Return "Filed to vault: {title}"
