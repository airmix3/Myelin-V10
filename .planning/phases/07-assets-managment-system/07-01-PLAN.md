```prisma
model Asset {
  id            String   @id
  title         String
  description   String?
  category      String           // code|brand|IP|digital-product|knowledge (per D-08)
  maturity      String   @default("nascent") // nascent|developing|established|foundational|legacy|heritage (per D-09)
  stewardId     String?          // agentId of assigned steward: cto/cmo/coo (per D-28)
  returnFactors String?          // JSON array: ["revenue","moat","core_tech","brand_equity"] (per D-24)
  annotations   String?          // JSON array of {text, createdAt} objects (per D-13)
  healthStatus  String   @default("healthy") // healthy|stale|degraded|critical (per D-31)
  directoryPath String?          // data/assets/{assetId}/ (per D-15)
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt

  events        AssetEvent[]
  locations     AssetLocation[]

  @@map("assets")
}

model AssetEvent {
  id        String   @id
  assetId   String
  type      String   // creation|promotion|annotation|maturity_change|steward_assessment|deliverable_absorbed|dependency_added|location_added|health_change (per D-14)
  summary   String
  metadata  String?  // JSON
  agentId   String?
  createdAt DateTime @default(now())

  asset     Asset    @relation(fields: [assetId], references: [id])
  @@map("asset_events")
}

model AssetLocation {
  id          String   @id
  assetId     String
  type        String   // local_path|github_url|platform_url|custom (per D-10)
  value       String   // The actual path/URL
  label       String?  // Human-readable label
  isCanonical Boolean  @default(false)
  createdAt   DateTime @default(now())

  asset       Asset    @relation(fields: [assetId], references: [id])
  @@map("asset_locations")
}

model AssetDependency {
  id          String   @id
  sourceId    String   // The asset that depends on...
  targetId    String   // ...this asset
  label       String?  // Relationship description
  createdAt   DateTime @default(now())

  @@map("asset_dependencies")
}
```

Create all asset API routes following the existing Next.js Route Handler pattern (NextResponse.json, prisma queries):

**`src/app/api/assets/route.ts`** (per D-01, D-08, D-15, D-28):
- `GET`: List all assets with `prisma.asset.findMany({ include: { events: { orderBy: { createdAt: 'desc' }, take: 5 }, locations: true }, orderBy: { updatedAt: 'desc' } })`. Also query `asset_dependencies` via raw sqlite for dependency counts.
- `POST`: Create asset. Body: `{ title, description, category, stewardId, returnFactors?, maturity?, initialLocation? }`. Generate ID with `generateId('asset')`. Create directory at `data/assets/{assetId}/` with `mkdirSync(dirPath, { recursive: true })`. Create Asset record. Create `creation` AssetEvent. If `initialLocation` provided, create AssetLocation record. Return 201 with asset object.

**`src/app/api/assets/[assetId]/route.ts`** (per D-09, D-13):
- `GET`: Single asset with full includes: events (all, ordered by createdAt desc), locations, plus raw sqlite query for dependencies (`SELECT ad.*, a.title as targetTitle FROM asset_dependencies ad JOIN assets a ON a.id = ad.targetId WHERE ad.sourceId = ?` and reverse query for dependents).
- `PATCH`: Update asset fields (title, description, category, maturity, stewardId, returnFactors, healthStatus). If maturity changes, also create a `maturity_change` AssetEvent with `summary: "Maturity changed from {old} to {new}"`. Update `updatedAt`.
- `DELETE`: Soft-archive: set a `healthStatus = 'archived'` or actually delete the record. For now, hard delete the Asset + cascade events/locations. Delete AssetDependency records where sourceId or targetId matches.

**`src/app/api/assets/[assetId]/events/route.ts`** (per D-14):
- `GET`: List events for asset, ordered by createdAt desc. Query param `?limit=50` (default 50).

**`src/app/api/assets/[assetId]/annotations/route.ts`** (per D-13):
- `POST`: Body: `{ text }`. Read current annotations JSON array from asset, append `{ text, createdAt: new Date().toISOString() }`, update asset.annotations. Also create `annotation` AssetEvent. Return updated annotations array.

**`src/app/api/assets/[assetId]/locations/route.ts`** (per D-10):
- `GET`: List locations for asset.
- `POST`: Body: `{ type, value, label?, isCanonical? }`. If `isCanonical: true`, first set all existing locations for this asset to `isCanonical: false`. Create AssetLocation with `generateId('aloc')`. Create `location_added` AssetEvent. Return 201.
- `PATCH`: Body: `{ locationId, isCanonical?, label? }`. Update the location. If setting canonical, unset others first.

**`src/app/api/assets/[assetId]/dependencies/route.ts`** (per D-11):
- `GET`: List dependencies for asset (both directions: assets this depends on, and assets that depend on this). Use raw sqlite for the recursive ripple query:
```typescript
const dependsOn = sqlite.prepare(
  'SELECT ad.*, a.title as targetTitle FROM asset_dependencies ad JOIN assets a ON a.id = ad.targetId WHERE ad.sourceId = ?'
).all(assetId);
const dependedBy = sqlite.prepare(
  'SELECT ad.*, a.title as sourceTitle FROM asset_dependencies ad JOIN assets a ON a.id = ad.sourceId WHERE ad.targetId = ?'
).all(assetId);
```
Also include ripple count via recursive CTE:
```sql
WITH RECURSIVE ripple(id) AS (
  SELECT sourceId FROM asset_dependencies WHERE targetId = ?
  UNION
  SELECT ad.sourceId FROM asset_dependencies ad JOIN ripple r ON ad.targetId = r.id
)
SELECT COUNT(*) as rippleCount FROM ripple
```
- `POST`: Body: `{ targetId, label? }`. Create AssetDependency with `generateId('adep')`. Create `dependency_added` AssetEvent on the source asset. Return 201.
- `DELETE`: Query param `?dependencyId=xxx`. Delete the dependency record.

All routes import from `@/lib/db` (prisma, sqlite), `@/lib/id` (generateId), and use `NextResponse` from `next/server`.
