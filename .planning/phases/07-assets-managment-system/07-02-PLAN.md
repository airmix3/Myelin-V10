- Description: "Update the health status of a company asset after a steward assessment."
- Parameters: `{ asset_id: z.string(), health_status: z.enum(['healthy','stale','degraded','critical']), narrative: z.string().describe('Steward assessment narrative explaining the health status') }`
- Implementation:

  - Return text: `Asset "${asset.title}" health updated to ${args.health_status}.`

**4. `link_asset_dependency`** (per D-11):
- Description: "Create a dependency link between two assets. The source asset depends on the target asset. Used to track ripple effects when assets change."

  - Verify both assets exist
  - Check for existing dependency (prevent duplicates): raw sqlite `SELECT id FROM asset_dependencies WHERE sourceId = ? AND targetId = ?`

  - Return text with ripple count from recursive CTE query
