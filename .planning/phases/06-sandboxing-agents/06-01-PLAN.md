Extend `buildCanUseTool` to accept workspace boundary paths and enforce filesystem restrictions on built-in Claude Code tools.

**Signature change:**
```typescript
export function buildCanUseTool(
  agentId: string,
  department: string,
  workspaceBoundaries?: { deskDir: string; delivDir: string }
): CanUseToolFn;
```

**Add a helper function `isPathAllowed`:**
```typescript
function isPathAllowed(targetPath: string, boundaries: { deskDir: string; delivDir: string }): boolean
```
- Resolve `targetPath` to absolute using `path.resolve(boundaries.deskDir, targetPath)` (handles relative paths from CWD)
- Return `true` if resolved path starts with `boundaries.deskDir` or `boundaries.delivDir`
- Return `false` otherwise

**Built-in tools to intercept** (these are the Claude Code built-in tool names):
- `Read` — input has `file_path: string`
- `Write` — input has `file_path: string`
- `Edit` — input has `file_path: string`
- `Glob` — input has `path?: string` (optional, defaults to CWD which is fine)
- `Grep` — input has `path?: string` (optional, defaults to CWD which is fine)
- `Bash` — input has `command: string` — check for common file-accessing patterns: if command contains absolute paths outside workspace boundaries, deny. Specifically scan for paths starting with `/` that don't start with deskDir or delivDir. Use a regex: `/(?:^|\s)(\/[^\s]+)/g` to extract absolute paths from the command string. If ANY extracted absolute path does not start with deskDir or delivDir, deny. Relative paths in bash are fine (they resolve within CWD which is the desk).

**Integration into existing callback:**
Insert the filesystem check BEFORE the existing MCP role-based checks. The logic flow should be:
1. If `workspaceBoundaries` is provided AND tool is a built-in tool (not starting with `mcp__`):
   - Extract the file path from `input` based on tool name
   - If a path is found and `!isPathAllowed(path, workspaceBoundaries)`: return `{ behavior: 'deny', message: 'Access denied: path outside workspace boundary' }`
   - For Bash: extract absolute paths from command, deny if any are outside boundaries
   - For Glob/Grep with no explicit path: allow (CWD-relative)
2. If no workspaceBoundaries (backward compat for any call without boundaries): skip filesystem check
3. Continue to existing MCP role-based checks

**Error message format:**
`"Access denied: [toolName] cannot access '${targetPath}' — outside workspace boundary. Use MCP tools (read_memory, read_knowledge, search_knowledge) to access shared resources."`

Per D-08: Do NOT restrict bash commands themselves — only deny when they reference files outside the workspace via absolute paths. Relative paths and commands without file references are allowed.

Import `resolve` from `path` at top of file (add `import { resolve } from 'path';`).
