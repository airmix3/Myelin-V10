Flow (per D-04 through D-08, UI-SPEC Tamir Page Flow):

1. **Initial state**: Full-width chat, no canvas (per D-07). Placeholder: "What would you like to get done?"

2. **First message** (`handleSend`):
   - Add CEO message to local messages state
   - `setIsLoading(true)`
   - POST `/api/tamir/route` with `{ message }`
   - On success: add Tamir response to messages, set routingButtons from response
   - Set taskId from response
   - `setIsLoading(false)`

3. **Route selection** (`handleRouteSelect`):
   - Set chosenAgentId
   - Clear routingButtons (hide buttons)
   - Add system message: "Planning with [agent name]..."
   - First planning message: POST `/api/tasks/${taskId}/message` with `{ message: "Let's plan this task.", agentId: chosenAgentId }`
   - Process turn response (see step 4)

4. **Planning turns** (`handlePlanningMessage`):
   - Add CEO message to local state
   - POST `/api/tasks/${taskId}/message` with `{ message }`
   - Process response turn:
     - Always add agent message to chat
     - If `turn.turn_type === 'plan_ready'`: set `showCanvas = true`, `setPlanMarkdown(turn.plan_markdown)` (per D-07)
     - If `turn.turn_type === 'plan_update'`: update planMarkdown
     - If `turn.turn_type === 'done'`: show completion state

5. **Page rehydration** (per D-16, D-17):
   - On mount, check URL for taskId param or localStorage for ongoing task
   - If taskId exists: GET `/api/tasks/${taskId}/chat` to load history
   - If task has artifact (planMarkdown): show canvas immediately, no typewriter replay
   - Populate messages state from JSONL history

Layout:
- When `showCanvas === false`: `<div style={{ height: 'calc(100vh - 48px)' }}><ChatPanel ... /></div>` (full-width)
- When `showCanvas === true`: `<div className="split-pane"><div className="split-chat"><ChatPanel ... /></div><div className="split-canvas"><CanvasPanel ... /></div></div>` (40/60 split per D-07)

Error handling:
- Tamir routing failure: show error message "Tamir could not route this request. Try rephrasing your task description." with Retry button
- Agent message failure: show error message in chat

Props interface:
```typescript
interface CanvasPanelProps {
  planMarkdown: string;
  taskId: string;
  isNewPlan: boolean; // true = typewriter effect, false = render immediately (rehydration per D-17)
  onApprove: () => void;
}
```

Implementation:

1. **Typewriter rendering** (per D-08: 40-70ms/line via marked.js):
   - State: `const [renderedContent, setRenderedContent] = useState('')`
   - State: `const [isTyping, setIsTyping] = useState(false)`
   - State: `const [isEditMode, setIsEditMode] = useState(false)`
   - State: `const [editContent, setEditContent] = useState(planMarkdown)`
   - Ref: `const containerRef = useRef<HTMLDivElement>(null)`

   - If `isNewPlan === true`: start typewriter on mount
     ```typescript
     useEffect(() => {
       if (!isNewPlan || !planMarkdown) return;
       setIsTyping(true);
       const lines = planMarkdown.split('\n');
       let i = 0;
       let accumulated = '';

       const timer = setInterval(() => {
         if (i >= lines.length) {
           clearInterval(timer);
           setIsTyping(false);
           return;
         }
         accumulated += lines[i] + '\n';
         setRenderedContent(accumulated);
         i++;
         // Auto-scroll
         if (containerRef.current) {
           containerRef.current.scrollTop = containerRef.current.scrollHeight;
         }
       }, 40 + Math.random() * 30); // 40-70ms per line

       return () => clearInterval(timer);
     }, [isNewPlan, planMarkdown]);
     ```

   - If `isNewPlan === false`: render immediately (full content, no animation)
     ```typescript
     useEffect(() => {
       if (!isNewPlan && planMarkdown) {
         setRenderedContent(planMarkdown);
       }
     }, [isNewPlan, planMarkdown]);
     ```

2. **Rendered view** (when NOT in edit mode):
   - `<div ref={containerRef} className="md-render" dangerouslySetInnerHTML={{ __html: marked.parse(renderedContent || planMarkdown) }} />`
   - If `isTyping`: show blinking cursor after content
     ```html
     <span style={{ animation: 'blink 0.6s infinite' }}>|</span>
     ```

3. **Edit mode** (per D-08):
   - Toggle button: "Edit Plan" (enters edit) / "Save Plan" (saves and exits)
   - In edit mode: `<textarea style={{ width: '100%', minHeight: '400px', background: 'var(--bg-3)', color: 'var(--text)', border: '1px solid var(--border)', fontFamily: 'var(--font)', fontSize: '13px', padding: '16px', resize: 'vertical' }} value={editContent} onChange={e => setEditContent(e.target.value)} />`
   - On "Save Plan": PUT `/api/tasks/${taskId}/artifact` with `{ plan_markdown: editContent }`, update local state, exit edit mode
   - On "Edit Plan": `setEditContent(renderedContent || planMarkdown)`, enter edit mode

4. **Action buttons** (bottom of canvas):
   - Button row: `<div style={{ display: 'flex', gap: '8px', marginTop: '16px', borderTop: '1px solid var(--border)', paddingTop: '16px' }}>`
   - "Edit Plan" / "Save Plan" toggle: `.btn` class
   - "Approve Plan": `.btn-approve` class — calls `onApprove()` which triggers the approval flow in TamirPage
   - Disabled states: Approve disabled while typing, Edit disabled while typing

5. **Styling**: The canvas panel sits in `.split-canvas` (from cortex.css). Content area scrollable with padding.
