  <action>
Create a new 'use client' component `NeuralHero` that renders a full-width hero section with an HTML5 canvas neural network animation behind overlaid content.

**Canvas setup:**
- Full-size canvas positioned absolutely inside the hero container (position: relative), behind text via z-index
- Use `devicePixelRatio` scaling for crisp rendering on HiDPI displays
- Handle resize events (debounced) to re-initialize canvas dimensions
- Use `requestAnimationFrame` for the animation loop; clean up on unmount

**Background:**
- Dark gradient: linear from #090816 through #0f1023, #15162d, with violet depth #24163f
- Applied as CSS background on the hero container (not drawn on canvas)

**Particles (nodes):**
- Generate 45-65 nodes on mount with normalized positions (0-1 range, mapped to canvas size)
- Each node: `{ x, y, vx, vy, radius (1.5-4), pulsePhase (random 0-2pi), brightness (0-1), fireTimer (0 = idle) }`
- Drift velocities: small random vx/vy (0.1-0.3 px/frame), bounce off edges
- Density highest near center: use gaussian distribution (Box-Muller) centered at 0.5,0.5 with sigma ~0.25
- Include 2-3 "hub" clusters of 5-8 tightly grouped nodes (random cluster centers, no symmetry)

**Connections:**
- Each frame, check pairwise distance; draw line if distance < 120px
- Line opacity: lerp from 0.2 (touching) to 0.05 (at 120px), fading with distance
- Line color: rgba based on the average of two node colors, with computed opacity
- Skip connections where both nodes have brightness < 0.1 (optimization)

**Node colors (neon palette, assigned randomly per node on init):**
- Cyan #8FE7FF, Electric blue #6496FF, Mint #2EE6A6, Magenta #FF64C8, Coral-red #E94560, Amber #FFB347

**Firing effect:**
- Every ~60-120 frames, randomly select 1 node to "fire": set fireTimer = 1.0
- Firing nodes: brightness ramps to 1.0, radius expands by 2x, decay fireTimer by ~0.015/frame (0.6-1.2s total)
- When a node fires, propagate to connected neighbors (distance < 120px) with 0.3x intensity and 10-frame delay

**Breathing effect:**
- Each node's rendered radius = baseRadius * (1 + 0.15 * sin(time * 0.5 + pulsePhase))

**Glow rendering (per node):**
- Layer 1: Large outer glow — arc with radius * 4, globalAlpha 0.08, fill with radialGradient from node color to transparent
- Layer 2: Medium bloom — arc with radius * 2.5, globalAlpha 0.15, similar gradient
- Layer 3: Sharp inner core — arc with base radius, globalAlpha 0.9, solid fill
- When firing (fireTimer > 0): multiply all alphas by (1 + fireTimer), expand radii proportionally

**Canvas compositing:**
- Set canvas element opacity to 0.7 via CSS (not globalAlpha)
- Use `globalCompositeOperation = 'lighter'` for the glow passes, reset to 'source-over' for connections

**Props interface:**
```typescript
interface NeuralHeroProps {
  title: string;           // e.g. "MYELIN v3"
  subtitle?: string;       // e.g. "The Cortex"
  stats: { label: string; value: string | number }[];
}
```

**Overlay content (rendered as absolutely positioned HTML over the canvas):**
- Title: large, bold, white, slight text-shadow for legibility
- Subtitle: smaller, dim text below title
- Stats row: flex row of stat items at bottom of hero (reuse the stat values from dashboard)
- All text content has z-index above canvas

The hero container should be ~350px tall (not full viewport).
