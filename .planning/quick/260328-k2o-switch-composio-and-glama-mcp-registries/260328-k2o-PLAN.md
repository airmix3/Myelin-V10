<objective>
Replace Composio and Glama MCP registries with Smithery.ai for querying and installing external MCP servers.

Purpose: Glama and Composio registries are unreliable (Glama has unknown API shape, Composio requires API key). Smithery has a public REST API at `https://registry.smithery.ai/servers?q=<query>&pageSize=<n>` returning structured JSON with qualifiedName, displayName, description, useCount, verified flag, and connectionUrl. Its CLI (`npx @smithery/cli`) provides `mcp search --json` and `mcp add <server> --client claude-code` for reliable installation.
Output: Updated search API, gallery UI, and install tool using Smithery as the single external MCP registry.
</objective>
