   - Parse the ANSI-stripped output. Each result line matches the pattern: `owner/repo@skill-name` followed by an installs count line like `57.5K installs`. Use a regex to extract these fields:

     - Actually the format from CLI output is: line 1 = `owner/repo@skill-name` (with ANSI codes), line 2 = `X installs` (with ANSI codes), line 3 = URL. Parse in groups of these.
   - Strip ANSI codes with: `.replace(/\x1b\[[0-9;]*m/g, '')`.
   - For each parsed result, create a SkillResult with:
     - `id`: `skillssh-${owner}/${repo}@${skill}`
     - `name`: the skill name part (after @)
     - `description`: `${owner}/${repo}` (the repo path)
     - `source`: `'skillssh'`
     - `stars`: parse install count (convert "57.5K" to number: parseFloat * 1000 if ends with K)
     - `summary`: not available from search results, leave undefined
   - Wrap in try/catch. On any error (timeout, not installed, etc.), set `sourceStatus.skillssh = 'unavailable'`.
