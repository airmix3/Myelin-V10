## One-liner

Fixed 200-second agent invocation timeout by removing hardcoded CLAUDE_CODE_USE_BEDROCK=1 — now uses Anthropic OAuth (2.5s response time)

## Root Cause

`invoke-agent.ts` hardcoded `CLAUDE_CODE_USE_BEDROCK: '1'` in the env passed to the SDK subprocess. The user's Claude Code installation uses Anthropic OAuth (stored in `~/.claude/.credentials.json`), not AWS Bedrock. The subprocess tried AWS Bedrock auth, found no credentials, and retried for ~200 seconds before returning an error disguised as a result.

## Fix

Removed the hardcoded `CLAUDE_CODE_USE_BEDROCK: '1'` from the env block in `invokeAgent()`. The subprocess now inherits the user's actual auth configuration via `...process.env`.

## Impact

- Before: Every agent call (routing, planning, execution) took ~200s and often failed
- After: Agent calls complete in 2-5s using Anthropic OAuth

## Key Files

- `src/lib/invoke-agent.ts` — removed hardcoded Bedrock env var
