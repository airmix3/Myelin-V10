       ```
       model Escalation {
         id          String   @id
         taskId      String
         agentId     String    // who escalated
         type        String    // clarification | hire_approval | budget_increase | custom
         urgency     String   @default("normal")  // low | normal | high | critical
         status      String   @default("pending")  // pending | responded | resolved | dismissed
         summary     String    // agent-provided summary
         reason      String?   // why escalation is needed
         context     String?   // JSON: type-specific fields (costEstimate, candidateRole, questionText, etc.)
         response    String?   // CEO's response text
         resolution  String?   // approved | declined | answered | custom
         createdAt   DateTime @default(now())
         updatedAt   DateTime @updatedAt
         resolvedAt  DateTime?
         task        Task     @relation(fields: [taskId], references: [id])
         @@map("escalations")
       }
       ```
       Also add `escalations Escalation[]` relation to the Task model.

    2. Run `npx prisma db push` to sync schema (SQLite, no migration files needed for dev).

    3. Create src/lib/mcp/tools/escalate.ts following the hire.ts pattern:
       - Export `createEscalateTools(ctx: ToolContext)` returning array with one tool
       - Tool name: `escalate_to_ceo`
       - Description: "Escalate an issue, question, or approval request to the CEO. Task will be paused pending CEO response."
       - Parameters (all z.string() or z.optional()):
         - `type`: z.enum(['clarification', 'hire_approval', 'budget_increase', 'custom'])
         - `summary`: z.string() — brief summary of what's needed
         - `reason`: z.string().optional() — detailed explanation
         - `urgency`: z.enum(['low', 'normal', 'high', 'critical']).optional().default('normal')
         - `context_json`: z.string().optional() — JSON string with type-specific data (costEstimate, candidateRole, questionText, etc.)
       - Handler:
         a. Create Escalation record via prisma with generateId('esc')
         b. Auto-enrich: fetch task title/department from DB, attach to escalation context
         c. Transition task to input-required using transitionTask(ctx.taskId, 'working', 'input-required', { inputType: 'escalation', escalationId })
         d. Update task metadata JSON with { inputType: 'escalation', escalationId }
         e. Emit eventBus.emit('escalation:created', { taskId, escalationId, type, urgency, agentId, summary })
         f. Return success text: "Escalation submitted to CEO. Task paused pending response."

    4. Register in src/lib/mcp/server.ts:
       - Import createEscalateTools from './tools/escalate'
       - Add `const escalateTools = createEscalateTools(ctx);`
       - Add `...escalateTools` to the tools array

    5. Create GET /api/escalations (src/app/api/escalations/route.ts):
       - Query params: ?status=pending (default), ?status=all
       - Return escalations with task title joined: `prisma.escalation.findMany({ where: status filter, include: { task: { select: { title: true, department: true } } }, orderBy: { createdAt: 'desc' } })`
       - Return JSON array

    6. Create POST /api/escalations/[id]/respond (respond/route.ts):
       - Body: { response: string, resolution?: 'approved' | 'declined' | 'answered' }
       - Update escalation: set response, resolution, status='responded', resolvedAt=now()
       - Update task metadata: clear inputType, add escalationResponse
       - Transition task back: transitionTask(taskId, 'input-required', 'working', { escalationResolved: true, escalationId })
       - Re-queue a task_run for the original agent (same pattern as hire approve: find previous run, create new queued run with sessionId for resume)
       - Emit eventBus.emit('escalation:responded', { escalationId, taskId, resolution })

    7. Create POST /api/escalations/[id]/resolve (resolve/route.ts):
       - For dismissing without response (CEO decides not relevant)
       - Update escalation: status='dismissed', resolvedAt=now()
       - Transition task back to working
       - Re-queue task_run same as respond
       - Emit eventBus.emit('escalation:resolved', { escalationId, taskId })
